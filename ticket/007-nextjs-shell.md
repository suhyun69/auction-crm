- [ ] 원화 숫자와 Asia/Seoul 시각 표시, 최고가 강조, 모바일 목록, 빈 상태·로딩·오류·연결 상태 표현을 준비한다.

- [ ] 선행 티켓이 반영된 최신 통합 브랜치 기준으로 검증했다.

- [ ] 통합 브랜치에 병합 후 관련 회귀 검사를 확인했다.

## 작업 절차

1. 루트 계획의 worktree 작업 규칙을 확인한다. 001은 worktree 생성 전 초기 기준 커밋이 필요하다.
2. 최신 통합 브랜치에서 위 브랜치와 worktree를 만들고 상태를 IN_PROGRESS로 변경한다.
3. 범위 안의 작업과 검증을 수행하고 결과를 기록한다.
4. 담당 서브에이전트는 결과를 루트에 보고한다. 루트가 최신 통합 브랜치를 반영하고 검증 후 병합한다. 완료 기준을 충족하면 루트가 DONE으로 변경한다.
5. 병합이 확인된 worktree와 브랜치를 정리한다.

## 결과 기록

- 변경 요약: `web/`에 공식 create-next-app 기본 프로젝트 생성. Next.js 16.4.6, React 19.3.0, TypeScript, App Router, Tailwind CSS, ESLint, src 디렉터리와 npm lockfile 포함. 이번 요청은 기본 프로젝트 생성까지이며 대시보드 화면과 API 연결은 미구현.
- 검증 명령 및 결과: `cd web && npm run lint` 통과. `npm audit --omit=dev` 취약점 0건. `npm run build`는 최초 Google Fonts 네트워크 제한으로 실패, 재시도에서는 Turbopack의 프로세스 포트 바인딩 권한 제한으로 실패.
- 미해결 사항: 일반 로컬 환경에서 production build 재확인 필요. 설치 시 개발 의존성 포함 audit에 high 14건이 보고됨. 저장소에 초기 커밋이 없어 이번 기본 생성은 현재 작업 폴더에서 진행했으며 worktree/브랜치/병합은 수행하지 않음.
- 작업 커밋: 미작성
- 병합 결과/커밋: 미작성 (병합 후 기록)
