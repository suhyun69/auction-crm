## 배경

시뮬레이션을 돌리는 동안 시뮬레이션 엔진 → API(응찰·조회), API → Web(SSE 알림), Web → API(대시보드 재조회) 사이에 실제로 어떤 호출이 오가는지 대시보드에서 바로 볼 수 없다. 대시보드 옆에 세 구성요소와 호출 흐름을 입체적으로 보여주는 인터랙티브 패널을 둔다.

## 작업과 완료 기준

- [x] 데스크톱에서 대시보드를 왼쪽 절반, 호출 흐름 패널을 오른쪽 절반에 둔다. 패널은 화면 높이에 고정되고 대시보드만 스크롤된다.
- [x] 1100px 미만에서는 위아래로 쌓고 패널을 접고 펼 수 있다. 대시보드 표는 절반 폭에서도 깨지지 않는다(container query).
- [x] 세션이 엔진의 API 클라이언트를 감싸 요청·응답(순번, 경로, 결과, 소요 시간)을 기록하고 스냅샷 `traffic`으로 내보낸다. 최근 200건만 보관한다. `core.mjs`와 `events`는 바꾸지 않는다.
- [x] 브라우저가 받은 SSE 알림과 대시보드 재조회를 같은 흐름에 기록한다.
- [x] CSS 3D(의존성 추가 없음)로 API·Simulation Engine·Web 노드와 연결선을 원본 그림 배치로 그린다. 드래그로 회전하고 시점을 초기화할 수 있다.
- [x] 호출을 경로를 따라 이동하는 패킷으로 재생한다. 응찰 요청·승인·기각·조회·SSE를 색으로 구분한다. 폴링으로 몰려 온 기록은 순서대로 간격을 두고 재생하고, 한꺼번에 많으면 묶어 표시한다.
- [x] 노드에 누적 호출 수·평균 응답 시간을 표시하고, 노드를 선택하면 해당 노드의 최근 호출을 보여준다. 종류별 표시 필터와 애니메이션 일시정지를 둔다.
- [x] 최근 호출을 텍스트 목록으로도 제공한다. 동작 줄이기 설정에서는 패킷 이동 애니메이션을 끈다.
- [x] 미리보기(dry-run)에서는 API 노드를 로컬 미리보기 시장으로 표시하고 Web 연결이 쓰이지 않음을 보여준다.
- [x] 시뮬레이터 세션 테스트·웹 테스트·lint·타입·production build와 데스크톱·모바일 브라우저 동작을 검증한다.
- [ ] 커밋과 `--no-ff` 병합, 병합 후 회귀 확인.

## 결과

- 변경 요약: 1100px 이상에서는 대시보드가 왼쪽 절반에서 따로 스크롤되고, 오른쪽 절반은 화면 높이에 고정된 `호출 흐름` 패널이다. 원본 그림 배치(위 API, 왼쪽 Simulation Engine, 오른쪽 아래 Web)를 CSS 3D 상자로 세우고 방향마다 차선을 하나씩 둬서 요청과 응답이 겹치지 않게 했다. 응답 패킷은 같은 호출의 요청 패킷이 API에 닿은 뒤 출발한다. 의존성은 추가하지 않았다.
- 데이터: 엔진 → API 구간은 서버 세션 기록(`run.traffic`), API → Web·Web → API 구간은 브라우저가 직접 관측한 SSE·재조회다. 폴링(1초)으로 몰려 오는 기록은 실제 간격 비율대로 0.9초 안에 펼치고, 한 번에 24개를 넘으면 응찰을 우선 남기고 나머지는 차선 옆 `+N`으로 묶는다. 화면을 연 시점에 이미 쌓여 있던 기록은 목록에만 넣고 재생하지 않는다.
- 검증: `npm run test:simulator` 73개 통과(신규 2개), `web` 테스트 27개 통과(신규 7개), `npm run lint` 경고 0, `npx --no-install tsc --noEmit` 통과, `npm run build` 통과.
- 브라우저 검증(Next dev 3100, `docker compose`의 실제 Spring API·PostgreSQL): live 1×·4× 실행에서 엔진 노드 `요청 47 · 승인 9`, API `처리 58건 · 평균 응답 15ms`, Web `SSE 12 · 재조회 13`이 갱신되고 응찰(파랑)·승인(초록)·SSE(보라)·재조회(청록)·조회(회색) 패킷이 각 차선을 따라 이동하는 것을 확인. 드래그 회전, 시점 초기화, 3D 면 위 실제 좌표 클릭으로 엔진 노드 선택·상세, `엔진 조회` 필터로 조회 패킷·목록 제외, 애니메이션 멈춤·재개를 확인. 미리보기 100×에서 API가 `API · 미리보기 시장`, Web 차선이 점선으로 바뀌고 안내와 `화면에 오기 전에 지나간 호출 46건` 안내가 뜨는 것을 확인. 1440·1100px 두 칸, 375px 세로 배치·가로 넘침 없음·접기/펼치기, 반쪽 폭에서 설정 모달이 화면 전체에 뜨는 것을 확인. 콘솔 오류 없음. `git ls-files --others --ignored` 소스 숨김 검사 통과.
- 확인한 정상 동작: 같은 DB에 이전 실행의 최고가가 남아 있으면 예산이 그보다 낮은 참가자는 응찰하지 않고 조회만 한다(이 경우 조회 패킷만 흐른다).
- 미검증: 동작 줄이기(`prefers-reduced-motion`) 설정에서 패킷이 이동 대신 도착 지점에서 깜빡이는 동작은 브라우저에서 설정을 바꿔 보지 못했다. 기각 패킷(주황)은 실행 중 경합이 없어 화면에서 보지 못했고 단위 테스트로만 덮었다.
